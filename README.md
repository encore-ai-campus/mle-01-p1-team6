# mle-01-p1-team6

알라딘 도서 데이터를 활용한 도서 분석·검색·추천 Streamlit 앱입니다.

## 실행

```powershell
uv run streamlit run streamlit_app.py
```

메인 앱에서는 다음 화면을 사용할 수 있습니다.

- 분석 대시보드: 카테고리·가격·평점 필터, KPI, 가격/순위 차트, 인기 도서 표
- 도서 도우미 AI: 자연어 질문을 바탕으로 Agent RAG 도서 추천
- 도서 검색: 제목·저자·출판사·책 소개 검색, 정렬, 페이지 이동, 알라딘 바로가기

기존 실행 명령과의 호환을 위해 `대시보드_진명.py`와 `검색기.py`도 유지했으며, 두 파일은 새 화면으로 연결됩니다.
